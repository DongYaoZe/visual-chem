# 《永远到不了的 100%》学习测试与教师审校方案

> 版本：0.1  
> 日期：2026-07-16  
> 用途：公开 Beta 前的人类证据门槛。本文是执行协议，不代表测试已经完成。

## 1. 要验证的不是“喜欢不喜欢”

首篇故事必须证明读者能够借三联动图完成以下转译，而不只是觉得动画好看：

1. 区分体积分数、质量分数和摩尔分数；
2. 解释为什么第一泡富含乙醇但不是纯乙醇；
3. 理解同一平衡状态中的液相 `x`、气相 `y` 具有相同温度而组成不同；
4. 区分文献实验点、读者重建草图和 Margules 教学模型；
5. 把共沸点解释成 `y(x)-x=0` 的不动点，而不是一堵任意画出的红墙；
6. 解释选择性脱水为何能越过普通精馏的不动点，却没有让热力学定律“失效”。

## 2. 参与者与伦理边界

- 第一轮招募 `5–8` 名正在学习或刚学完大学物理化学、但没有参与本项目开发的学生；
- 至少覆盖一名第一次接触二元 `T-x-y` 图的学生和一名已经学过精馏的学生；
- 测试前说明用途、预计时长、退出权利和是否录屏；拒绝录屏不影响参与；
- 记录使用匿名编号，不收集姓名、学号、手机号等不必要身份信息；
- 原始录屏不进入公开仓库，公开材料只保留去标识化的问题摘要和聚合指标。

## 3. 测试流程（每人约 35–45 分钟）

### A. 前测（5 分钟）

使用 6 道不依赖页面措辞的概念题，每题 1 分：

1. 给出液体乙醇摩尔分数 `x=0.10`，第一泡最可能是纯乙醇、同组成还是乙醇更富集？
2. 一条水平结线两端分别表示什么？
3. 总组成 `z` 与两相组成 `x、y` 的区别是什么？
4. 若某点满足 `x=y`，再做一个理想平衡级会怎样改变组成？
5. “95.5 wt%”能否直接当作 `x=0.955`？为什么？
6. 分子筛脱水是否仍是一个气液平衡级？

前测只记录答案和一句理由，不立即纠正。

### B. 出声思维任务（20–25 分钟）

主持人只使用中性提示“请继续说出你正在看什么、为什么这样操作”，不得提前解释答案。

| 任务 | 成功证据 | 重点观察 |
|---|---|---|
| 在第 0 幕下注并增加至少 6 级 | 能说出读数仍变化但增量变小 | 是否把“越来越慢”误当成已经精确停止 |
| 在第 2 幕预测第一泡 | 选择“乙醇更丰富”并说明水仍挥发 | 是否把易挥发误解为只有乙醇进入气相 |
| 在第 4 幕选择 5 组文献数据 | 能指出圆是 `(x,T)`、三角是 `(y,T)` | 是否把用户虚线当成新实验或精确拟合 |
| 比较完整实验点与模型 | 能说出点是测量、平滑线是模型 | 是否因曲线平滑而默认它比实验“更真实” |
| 拖动 `λ` 并描述变化 | 明确 `λ` 是讲解拨杆，不是可测物性 | 是否把中间值当作真实混合物参数 |
| 在第 7 幕寻找 `y-x≈0` | 用“不动点”解释精馏极限 | 是否把实验 `0.891±0.004` 与模型 `0.895` 说成完全相同 |
| 完成分子筛概念题 | 选择“改变分离机制”并给出物料衡算理由 | 是否认为分子筛关闭了共沸定律 |
| 自由实验从 `x0=0.95` 级联 | 判断阶梯向左靠近共沸点 | 是否认为只要起点高于共沸就会继续走向 100% |

每项同时记录：完成/失败、首次操作时间、是否需要主持人救援、原话中的误概念和界面卡点。

### C. 后测与访谈（10 分钟）

- 使用与前测同构但数值/表述不同的 6 道题；
- 要求参与者不看页面，用纸笔画出一条结线并标注 `x、y、z`；
- 单题询问：“空心符号、粗虚线、平滑线分别是什么证据？”；
- 记录 7 点单题易用度评分（SEQ）：“完成这篇故事的核心任务有多容易？”；
- 最后才询问主观喜欢/不喜欢，避免把审美评价替代学习证据。

## 4. Alpha 升 Beta 的通过标准

必须同时满足：

1. 至少 5 名有效参与者完成全流程；
2. 核心任务在无主持人救援下完成率不低于 `80%`；
3. 后测相对前测的中位数提升至少 `2/6`，且没有参与者显著倒退；
4. 至少 `4/5` 能准确区分“实验点 / 用户草图 / 教学模型”；
5. 至少 `4/5` 能用 `y=x` 或“不动点”解释普通精馏极限；
6. 不出现系统性严重误导：例如多数人把粒子运动当成分子动力学、把模型值当实验真值、或把分子筛理解为关闭热力学；
7. 所有阻断任务、错误科学结论、键盘/读屏不可达问题都在发布前修复并复测。

若指标未过，继续保持 Alpha；不能通过删题、换更熟练的参与者或只报告平均满意度来“达标”。

## 6. 物理化学教师审校

至少邀请 1 名讲授过物理化学或化工热力学的教师，逐项签字或留下具体异议：

### 科学内容

- Antoine 方程的单位、常数和有效温区是否清楚；
- 修正拉乌尔定律、三后缀 Margules 公式和 `x/y` 定义是否一致；
- “理论平衡级”是否避免冒充真实塔板、回流塔或批式 Rayleigh 蒸馏；
- 结线与杠杆规则是否把端点组成和相量区分开；
- 共沸点是否准确表述为给定压力下的实验结果与模型不动点；
- “常压下约 95.5 wt%”是否正确表达实验差异和不确定度；
- 分子筛段是否只声称选择性移水与物料衡算，不夸大具体工业工艺性能。

### 证据与模型边界

- Lai 2014 / NIST ThermoML 的 16 组数据、数据集编号、转换和不确定度是否引用完整；
- 空心实验符号、用户虚线和模型曲线是否不会被混淆；
- `λ` 拨杆是否始终标成教学形变；
- 当前 Margules 残差与“不可压力外推、不可工业设计”是否足够醒目；
- 微观粒子只有比例定量，位置、碰撞和时间均明确为解释性示意。

### 教学表达

- 每幕是否只引入一个主要新概念；
- 预测题是否诊断真实误概念，而不是考措辞记忆；
- 公式出现前是否已有宏观或数据问题需要它解决；
- 折叠模型卡是否足以供教师追溯，不打断主叙事。

审校结论只允许三种：`通过`、`修改后通过`、`不通过`。任何科学性异议必须记录处理结果；不能只写“老师看过”。

## 7. 发布时公开什么

Beta 发布说明公开：参与人数、先验背景分布、任务完成率、前后测聚合结果、最重要的 3–5 个修改，以及仍未解决的限制。不要公开可识别个人的原话、录屏或原始表格。
