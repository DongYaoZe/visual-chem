### 架构（审计第 7–9 项落地）

- `thermo-frame.ts`：`thermoFrame()` 一次解析曲线/级联/当前点/共沸/参考温度范围（按输入元组记忆化、对象恒等稳定）；`TriView` 顶层解析后下传，`TxyDiagram` 变为纯视图，故事速览条引用同一 frame——顺带修复了级联运行时速览条 y 值不随级数更新的缺陷。
- `scrolly.ts`：场景追踪 IntersectionObserver 抽成 action，全站共用一份观察器调参（rootMargin/thresholds 由 spec 钉住）。
- `StoryStage.svelte`：粘性图形 + 短视口对话框状态机（焦点陷阱、Escape、视口变大自动关、body 滚动锁）与状态条抽成组件，故事组件只保留自己的叙事。

### 故事二《沸腾的地图》（九幕全量上线，中英双语）

- 计算层 `water-pt.ts`：汽化线用 IAPWS-IF97 区域 4 解析式（正反双向一致，无迭代）；冰 Ih 熔化/升华线用 IAPWS R14-08(2011)；国际标准大气 0–11 km 段做海拔—压强换算；Clausius–Clapeyron 斜率读数明示约 1.5% 理想气体偏差。Vitest 钉住 IF97 Table 35/36 与 2011 版 Table 3 的官方程序验证值,外加常压 100 °C、常压冰 0 °C、拉萨约 88 °C、三线在三相点相接等锚点。
- 状态层 `water-frame.ts`：`waterFrame()` 一次解析 (T,p) → 相区/沸点/饱和压/是否沸腾；方程适用域之外返回 null 而不是抛错。
- 舞台 `WaterTriView`：宏观灶台（是否翻滚由计算判断）、微观液面竞赛（逃逸/回落流量比来自 p*/P）、`WaterPTDiagram`（固定对数压强窗口、三条边界、外压线、ln p–1/T 直线化切换、冻干虚线路线、三相/临界点标注）。
- 叙事九幕：拉萨钩子预测 → 液面竞赛 → 画出曲线 → 沸腾定义（外压线可拖）→ 拉直曲线（ΔH≈41 kJ/mol 读数）→ 地图完整（三相点/临界点/负斜率熔化线）→ 海拔旅行（海平面/丹佛/拉萨/珠峰地标）→ 冻干绕行（程序滑杆沿 log 压强插值，spec 证明腔压确在 −30 °C 升华压之下）→ 高压锅反转。临界点插曲、概念题、(T,p) 双旋钮沙盒、IAPWS 模型卡、结尾页齐全。
- 场景对齐 spec 与故事一同构：zh/en/舞台指令三方 id 顺序一致；故事锚点（拉萨 85–90 °C、高压锅 119–122 °C）由测试钉住。
- 路由 `/stories/boiling-map/`（+ `/en/`）预渲染；首页第二张故事卡变为可点链接；sitemap 更新；OG 分享图由 `scripts/render-og.mjs` 从 SVG 渲染。

## 已完成

### 产品与叙事

- 建立 SvelteKit 5 + TypeScript + MDsveX 的静态站点，可零服务器部署到 GitHub Pages。
- 完成首页的编辑型视觉系统，不沿用旧 Streamlit 控制面板语言。
- 完成《永远到不了的 100%》九幕滚动原型：预测、组成定义、首泡、x/y 结线、T-x-y 图、理想级联、非理想模型、不动点与选择性脱水反转。
- 完成“亲手重建相图”一幕：读者从 Lai 2014 的 16 组真实文献数据中选择至少 5 组，先画自己的边界草图，再展开完整实验点与模型对照。
- 提供作者控镜后的自由探索区；读者可调初始组成、理论级数与非理想强度。
- 明确显示“理论平衡级”“教学模型”“微观轨迹为示意”等证据边界。

### 三重表征组件

- `DistillationApparatus.svelte`：宏观烧瓶—冷凝—接收装置，组成和泡点同步。
- `ParticleChamber.svelte`：液/气两相的乙醇/水比例同步；粒子位置与运动不冒充分子动力学。
- `TxyDiagram.svelte`：实验点及不确定度、用户重建草图、模型泡/露点线、结线、实验/模型共沸点与逐级精馏阶梯；形状和线型不只依赖颜色。
- `TriView.svelte`：按叙事幕聚焦与降噪组合三幅图（2026-07-17 起由单一 `thermoFrame()` 状态源驱动，TxyDiagram 为纯视图，审计第 7 项已闭环）。
- `ConceptCheck.svelte`：先选择预测，再给因果解释。

### 计算与验证

- 从 `app.py` 抽出 Antoine、三后缀 Margules、泡点、露点、共沸、flash、组成换算与理论级联的无 UI TypeScript 内核。
- 发现并隔离旧乙醇—水预设的定量错误：旧模型给出约 `89.0 wt%` 共沸，新 Alpha 校准到约 `95.6 wt%`。
- 从 NIST ThermoML 原始 JSON 落地 Lai 2014 的 16 组常压 `x–T–y` 数据、逐点 95% 扩展不确定度和独立共沸点；页面物理事实统一写“约 `95.5 wt%`”。
- 将 Kamihama 2012 的另一实验室 21 点作为独立验证集：与 Lai 的共同网格差异为 `0.224396 K / 0.0077243 y`；验证资产不接入故事主曲线，也不与校准集混合。
- 量化而不隐藏模型偏差：当前 Margules 相对 16 个实验点的温度 RMS 约 `0.57 K`、气相组成 RMS 约 `0.016`。
- 当前 Margules 在独立 Kamihama 21 点上的 RMS 为 `0.777318 K / 0.0197836 y`。
- 用独立 SciPy `brentq` 脚本生成 10 个跨语言 golden points，Vitest 对照温度、气相组成与活度系数。
- 已覆盖共沸不动点、纯组分、露点直接求解、杠杆规则闭合和逐级精馏不穿越共沸点。

## 本地验收

```powershell
# 8 GB 内存的机器上建议先设定堆参数，否则 prerender 子进程可能因系统
# 内存承压出现 "Committing semi space failed" 崩溃（CI 上已设 4096）：
$env:NODE_OPTIONS = "--max-old-space-size=768 --max-semi-space-size=8"

npm --prefix web install
npm --prefix web run validate
npx --prefix web playwright install chromium
npm --prefix web run test:e2e
```

视觉验收可以对开发服务器，也可以对生产产物：

```powershell
# 开发服务器（默认 5173）
npm --prefix web run dev -- --host 127.0.0.1
npm --prefix web run audit:visual

# 或对生产产物（GitHub Pages 语义，端口 4173）
npm --prefix web run build
npm --prefix web run serve:pages
$env:VISUAL_CHEM_ORIGIN = "http://127.0.0.1:4173"
npm --prefix web run audit:visual
```
