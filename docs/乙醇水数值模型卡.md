## 为什么没有直接迁移旧 Streamlit 参数

旧版 `app.py` 的乙醇—水预设使用单参数对称 Margules `A=1.6`。公式本身没有写错，但参数会在 `1.013 bar` 下预测：

- 共沸乙醇摩尔分数 `x_E = 0.760645`；
- 共沸温度 `T = 76.0216 °C`；
- 换算乙醇质量分数约 `89.04 wt%`。

这与常压实验给出的 `x_E≈0.891–0.895`、`T≈78.2 °C`、约 `95.4–95.6 wt%` 相差太大，不能支撑一篇以真实酒精精馏极限为钩子的故事。因此旧参数只保留为历史原型，不作为新站点的定量真值。

## 连续教学模型

### 1. 纯组分饱和蒸气压

采用 Antoine 方程，压力基准为 mmHg，输出换算为 bar：

```text
log10(p_i* / mmHg) = A_i - B_i / (T / °C + C_i)
```

| 组分 | A | B | C | 代码中的有效温区元数据 |
|---|---:|---:|---:|---:|
| 乙醇 | 8.20417 | 1642.89 | 230.300 | 0–78.3 °C |
| 水 | 8.07131 | 1730.63 | 233.426 | 1–100 °C |

常压下代码得到纯乙醇沸点 `78.3192 °C`、水沸点 `99.9968 °C`。

### 2. 液相非理想性

采用三后缀 Margules：

```text
ln γ_E = x_W² [A_EW + 2(A_WE - A_EW)x_E]
ln γ_W = x_E² [A_WE + 2(A_EW - A_WE)x_W]
```

Alpha 参数为：

```text
A_EW = 1.39081729
A_WE = 0.95455763
```

这两个参数根据常压目标点 `x_E=0.895, T=78.15 °C` 处的修正拉乌尔定律联立求得，使该点满足：

```text
γ_E p_E* = γ_W p_W* = P
y_E = x_E
```

它不是对整条实验 VLE 数据的统计回归。页面因此始终使用“教学模型”“常压近似”和“Alpha”标签，不能写成“高精度真实乙醇—水模型”。

### 3. 泡点与气相组成

给定液相组成 `x_E` 和压力 `P`，数值求解：

```text
x_E γ_E p_E*(T) + (1-x_E) γ_W p_W*(T) - P = 0
```

再计算：

```text
y_E = x_E γ_E p_E*(T) / P
```

浏览器内使用确定性的括区求根；露点由 `y(x)-y_target=0` 直接求解，不再像旧 UI 那样从 200 个网格点中取最近值。

### 4. 理论平衡级

故事中的“再加一级”采用：

```text
x_(n+1) = y(x_n)
```

它表示“平衡蒸气被完全取出并冷凝成下一锅液体”的理想级联，不等同于真实精馏塔，也不包含回流比、Murphree 效率、压降、传质速率或批式 Rayleigh 物料衡算。

## 模型与实验不是同一层

把当前 Margules 教学模型逐点与 Lai 16 组实验数据比较：

| 残差指标 | RMS |
|---|---:|
| 泡点温度 | 约 0.57 K |
| 气相乙醇摩尔分数 `y_E` | 约 0.016 |

在完全独立的 Kamihama 21 点上，当前 Margules 模型的 RMS 为 `0.777318 K / 0.0197836 y`。独立集误差高于校准所参照的 Lai 数据，再次说明这套参数只适合教学解释，不是高精度全域回归。

这说明单点校准可以复现共沸拓扑，却不能冒充整条实验曲线的高精度回归。页面因此用空心符号表示实验、平滑线表示模型，并在第 06 幕才把两者叠加；`0<λ<1` 只表示讲解用形变，不是材料可测参数。

## 跨语言验证

参考实现位于：

- `validation/generate_ethanol_water_reference.py`：NumPy/SciPy 之外只使用标准库，根由 `scipy.optimize.brentq` 求解；
- `web/src/lib/chem/fixtures/ethanol-water-python.json`：10 个覆盖 `x=0…1` 的 Python golden points；
- `web/src/lib/chem/ethanol-water.spec.ts`：TypeScript 对温度与气相组成验证到小于 `1e-6`，并检查纯组分、共沸点、露点、杠杆规则闭合与逐级精馏不穿越共沸点；
- `web/src/lib/chem/data/ethanol-water-lai-2014.spec.ts`：检查 16 行顺序、K/°C 换算、独立共沸点、不确定度和模型残差区间。
- `web/src/lib/chem/data/ethanol-water-kamihama-2012.spec.ts`：检查独立 21 行、逐点不确定度、无外推的跨实验室比较和 Margules 独立残差。


## 明确的适用边界

模型包含：

- Lai 2014 在 `101.3 kPa` 下的 16 组实验 `x–T–y` 参考点及不确定度；
- 常压、理想气相；
- 修正拉乌尔定律；
- 三后缀 Margules 常数参数；
- 泡点、露点、共沸点、简单 flash/杠杆规则与理想平衡级联。

模型不包含：

- 完整实验 VLE 数据回归和温度相关参数；
- NRTL/Wilson/UNIQUAC 的文献参数及其置信区间；
- Poynting 修正、气相逸度系数和高压适用性；
- 塔板效率、回流、连续塔物料衡算和真实时间尺度；
- 任何分子动力学。粒子圆点只有组成比例是定量的，位置与运动均为解释性示意。

## Beta 前仍需完成的数值门槛

1. 若未来需要比当前 Margules 更高精度的连续内核，应从公开实验数据自行回归温度相关模型，并公开参数协方差、残差图和交叉验证；不能只换一组来源不明的参数。
2. 将压力交互限制在全部 Antoine 和活度参数共同有效的范围；没有实验证据前不开放“变压精馏”定量结论。
3. 把旧 Streamlit 模型加入显式 `legacy` 兼容测试，避免“对数一致”被误解成“物理真实”。
