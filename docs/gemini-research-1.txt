打造为全球领先的大学化学可视化平台，必须对现有的可视化技术栈、教学法理论及前沿人工智能架构进行系统性整合。高等化学教育的核心痛点在于：学生难以在宏观（热力学现象）、微观（分子动力学行为）以及符号（相图、状态方程曲线）这三种尺度（即“化学三重表征”）之间建立自发的、深度的逻辑映射。本报告对全球市面上主流的可视化方案进行多维调研，并据此为 visual-chem 的下一阶段升级提供一份详尽、雄心勃勃的平台建设方案。现行化学可视化与教学模拟平台的多维技术透视当前全球范围内的化学可视化与教学模拟工具呈现出高度细分、各具特色但又彼此割裂的生态格局。下表对这些典型工具的技术栈、应用场景及核心局限进行了系统性梳理：平台与项目分类典型代表核心技术栈核心优势教学叙事能力与局限性高精度热力学与过程模拟器DWSIM、LearnChemEVB.NET、C#、Python、JavaScript、WebGL内置彭-罗宾逊（Peng-Robinson）、SRK 多种热力学方法，能实现多盐沉淀及复杂的汽液平衡（VLE）和固液平衡（SLE）求解。然而，这类平台的设计初衷是面向化工工程设计而非高等教育教学。相较之下，科罗拉多大学的 LearnChemE 项目在教学转化上做出了极大贡献，其开源库包含了一系列基于 Web 的交互式仿真，涵盖了三元相图、温度-熵（T-S）图、压力-体积（P-V）图以及压力-焓（P-H）图等。这些仿真通常配备了活塞气缸等物理量表征（如液体用蓝色，蒸汽用绿色），但其视觉设计风格、跨尺度联动性及现代网页叙事逻辑仍有巨大提升空间。分子结构、三维渲染与化学空间分析工具在三维分子渲染领域，Jmol/JSmol、py3Dmol 和 nglview 提供了解析、读取及在浏览器中无缝渲染复杂生物大分子及小分子配体结构的成熟方案。chemical_visualizer 通过 CMake 和 Emscripten 将 OpenGL 3.3 编译为 WebAssembly，证明了在网页端高性能绘制蛋白核糖图的可行性。在 Cheminformatics 领域，ChemPlot 基于 Mordred 计算分子描述符，利用 RDKit 和机器学习流对化学空间进行二维可视化。然而，这些工具目前都局限于单个分子或静态化学集合的结构表征，无法将其与系统的宏观热力学状态（如在相平衡点上，水分子的微观氢键网络和运动速度的变化）进行跨越尺度的实时双向绑定。材料科学、计算相图与量化反应路径工具科研级的相图绘制工具如 SurfinPy 和 pysurf，利用 Python 直接从 DFT 计算出的表面形成能和化学势数据中生成相图。phaseGP 则采用高斯过程（GP）分类模型与主动学习算法，以最小的计算代价描绘相空间边界。在反应路径可视化上，chem-diagrams 支持绘制带有多条过渡态路径和能量断点的高精度化学反应坐标图。上述工具的主要痛点在于：它们输出的都是 Matplotlib 等静态图像，主要用于学术论文发表。它们不具备教学上的“渐进式探索”功能，也无法在学生调整反应物能量时实时、动态地模拟过渡态分子发生键断裂与重新键合的物理机制。交互式游戏化与概念探究模拟平台科罗拉多大学的 PhET 交互模拟系统是全球 K-12 及大学基础化学教育的标杆，其以游戏化的探索和及时的交互式图形反馈见长。然而，随着化学教育走向高阶（如物理化学、高分子化学、化工热力学），PhET 的热力学模型过于简化，无法支持学生输入自定义物性参数，更无法进行多相、多组分非理想混合物的平衡态计算。认知冲突与多表征整合：相图叙事化设计的物理与认知科学机理大学化学可视化要实现真正的“深入浅出”，不能仅仅追求画面华丽，而必须遵循认知科学中有关“表征转换胜任力”的培养规律。表征转换胜任力与多维动态链接化学教学通常依赖多幅视觉图表，例如在讲授原子结构时需要同时展示路易斯结构、壳层模型、能量图和轨道图。认知心理学研究指出，如果缺乏明确的转换逻辑，多种图表的堆砌非但不能促进理解，反而会大幅增加学生的认知负荷。因此，visual-chem 的核心叙事技术必须建立在“动态链接表征（Dynamic Linked Representations, DLRs）”的基础之上。在系统的设计中，学生的任何一次交互都必须产生三轴一体的实时响应：宏观物理现象表征：显示活塞膨胀、容器起雾、晶体析出等真实物理场景。微观粒子行为表征：实时运行分子动力学碰撞、氢键网络断裂、晶格有序化生长等纳米级动画。抽象符号与热力学曲线表征：动态推演相图上的状态点、吉布斯自由能（$G$）切线、逸度与活度系数随温度和压力的移动轨迹。认知冲突的构建：负斜率熔化线与异常物性叙事性教学的精髓在于，用反直觉的物理现象在学生脑海中激发起强烈的认知冲突。
以水（$\text{H}_2\text{O}$）和二氧化碳（$\text{CO}_2$）单组分相图的对比故事为例：对于大多数物质，其固液共存线（熔化线）在 $P-T$ 相图上拥有正斜率，这意味着增大压力会驱使液态向固态转化。然而，水的熔化线斜率却是负值。教学叙事线索：设计一个“冰面滑行与深海游鱼”的故事。引导学生在相图上沿着等温线向冰施加极高压力，他们会震惊地发现，冰并没有被压得更实，而是融化成了液态水。跨尺度表征关联：此时，微观窗口必须同步展现其物理机制——在常压下，冰中水分子通过高度定向的四配位氢键，撑起了一个低密度的开阔笼状晶格；当施加高压时，这一氢键网路在物理上发生扭曲和局域崩溃，促使分子间距缩小，从而转化为密度更高的液态水。通过这种方式，相图的“几何斜率”在微观的“氢键物理本质”上找到了完美的因果解释，完成了深度的教学叙事闭环。杠杆规则与金相显微组织的动态跨尺度演变在学习二元合金相图（如铅锡合金、铁碳合金）时，杠杆规则的计算往往被学生视为枯燥的纯数学公式。教学叙事线索：让学生扮演一名冶金铸造师，目标是铸造一枚兼具韧性与硬度的金属工件。跨尺度表征关联：当学生在 $T-x$ 相图上拉动温度滑块进行降温时，相图上的杠杆线随之动态伸缩，并实时计算、输出固液两相的瞬时质量分数。右侧的显微组织窗口则利用相场法（Phase Field）实时演化出生动逼真的微米级金相演变——绿色的初生富铅 $\alpha$ 树枝晶在液相中不断成核并分叉生长；当温度越过共晶线时，剩余的液相在晶界缝隙间爆发式地交替生长出层片状的 $\alpha + \beta$ 共晶组织。学生能够直观、动态地看到“相图上的质量分数”如何一点一滴地转化为“金属中层片状和枝状显微组织的长大过程”。visual-chem 2.0 平台雄心勃勃的系统架构与产品方案为了实现这一目标，visual-chem 2.0 的系统架构必须进行彻底重构。其不应仅仅是一个绘制相图的轻量级前端库，而应演进为一个兼具“高保真热力学计算”、“多尺度物理渲染”与“多模态 AI 启发式叙事”的高性能 Web 教学平台。底层解算与多尺度渲染架构为了保证在大规模物理交互和拖拽时的流畅度，系统将全面采用“计算内核（WASM）+ 渲染管线（WebGL/WebGPU）+ 数据绑定（Reactive States）”的现代 Web 架构：+-----------------------------------------------------------------------------------------+

PSI4）的电子云和轨道计算。跨尺度物理引擎：纳米级（3D 粒子动力学）：使用 Lennard-Jones 12-6 势能函数实时计算数千个原子的运动速度、轨迹与碰撞，真实展现随温度与压力变化的宏观物理态。微米级（相场变分法）：引入简化的 Allen-Cahn 相场控制方程，在 GPU 中实时演算晶粒凝固、枝晶成核、偏析及晶界粗化等金相微观演变。响应式 MDX 叙事引擎设计开发专门面向化学教学的 MDX 叙事解释器。这一引擎允许教学内容创作者以 Markdown 驱动的多模态教学导师与评估系统仅仅展现漂亮的画面是不够的，系统需要实时得知学生在看图时是否产生了真正的化学理解。整合 TinyChemVL 视觉-语言大模型：TinyChemVL 等模型在复杂的化学视觉识别、分子图谱关联上具备 AAAI 2026 级别的先进表现。通过将其部署在云端或本地轻量级推理端，系统可以实时感知学生在前端界面上的操作轨迹（例如在三相点、共晶点附近的来回摩擦或乱动）。RxnBench 启发式教学机制：借鉴 RxnBench 中 Single-Figure QA (SF-QA) 针对图形进行细粒度视觉感知和物理机制推理的评测思想，AI 导师可以自发、主动地向学生推送启发式问题。例如：“当你在共晶线以下继续降温时，为什么共晶层片中 $\alpha$ 相的厚度不再明显发生变化？”模型在学生作答后，结合“Human-in-the-Loop”高质量 QA 知识库，指出学生对“非平衡固态扩散受温度控制限制”这一机制的盲区，引导其通过微观窗口中的原子热振动频率减慢现象去寻找解释。二元共晶系统（Pb-Sn）非平衡凝固的叙事交互方案实例为了向全球化学界演示 visual-chem 2.0 的独特魅力，本方案精细策划了一场关于铅锡合金（$\text{Pb-Sn}$ 系统）非平衡凝固的叙事化教学方案。铅锡合金是非平衡共晶凝固教学的绝对痛点——非平衡凝固往往在极短时间内发生，传统的教科书静态图表完全无法向学生展示晶粒在热力学非稳态下如何形成化学成分偏析。宏观-微观-符号三维一体联动叙事矩阵下表展示了当学生在 $T-x$ 相图上缓慢拖拽降温滑块时，系统如何在不同尺度上动态演绎并讲好这个“凝固的故事”：教学故事情节与认知冲突相图与热力学状态 (符号表征)金相微观组织演化 (微米级表征)原子级协同运动 (纳米级表征)熔体无序：熵主导的混乱“在熔点以上，热运动彻底击碎了晶格。没有长程有序，系统处于最高的混乱之中。”温度滑块在液相线以上，$T > T_{\text{liquidus}}$。相图上的状态点停留在单相液体区 $L$。显微镜下呈现完全均匀、无特征的熔融背景。铅（绿色球）和锡（橙色球）原子在容器中高速碰撞，彼此间杂，没有形成任何稳定的有序晶核。孕育新相：破缺的对称性“温度跌落至液相线。热运动不再能抗衡原子间的键合力，最初的固态结晶核在熔体中生根发芽。”状态点穿过液相线。杠杆规则启动，计算出初生固体 $\alpha$ 相的摩尔分数 $f_{\alpha}$ 极小。画面中随机成核并向外生长的绿色“树枝晶”（富铅固溶体 $\alpha$）。局部区域的铅原子开始自发排列成有序的 FCC 晶体结构，而多余的锡原子则被排挤并积聚在晶界边缘。枝晶生长与非平衡偏析“晶粒正在掠夺液体中的铅原子。由于温度迅速下降，原子来不及均匀扩散，导致晶粒内部成分极不均匀。”随着滑块向下移动，相图上的杠杆线快速伸展，液相端点沿着液相线滑落，残余熔体的锡浓度快速积聚。绿色的 $\alpha$ 树枝晶迅速变粗，其内层（最早凝固部分）富铅，外层（后凝固部分）由于偏析堆积了较多锡。固液交界前沿由于非平衡固化形成了明显的“溶质富集边界层”。扩散受到温度降低的物理压制。共晶狂欢：层片的诞生“我们到达了最奇特的地标——共晶温度。此时系统自由度降为 0。剩余的液体必须在瞬间同时凝固。”温度滑块精确停留在共晶线。根据相律 $F=C-P+1=2-3+1=0$（由于常压，多余的一个自由度被消去）。在已生长的 $\alpha$ 枝晶间隙中，残余的液相突然爆发，交替结晶出黑白相间的平行的 $\alpha$ 和 $\beta$ 层片状共晶组织。在凝固锋面上，铅和锡原子发生了局部的“原子协同分流扩散”：铅原子迅速并入 $\alpha$ 晶格，而退回的锡原子就地并入相邻的 $\beta$ 晶格。核心物理公式与算法实现该模拟绝非简单的视觉特效，而是通过以下严格物理方程的数值解法驱动：杠杆规则的动态解算模型对于初始成分为 $x_0 = 30 \text{ wt.\% Sn}$ 的系统，当温度从液相线降至共晶温度以上某个值时，插值得出固相边界成分为 $w_{\alpha}$，液相边界成分为 $w_L$：$$\alpha \text{ 相的瞬时质量分数 } W_{\alpha} =
