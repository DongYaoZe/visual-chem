## 一、项目是什么

**VisualChem**:大学化学叙事可视化网站。SvelteKit 5 + TypeScript 静态站,GitHub Pages 部署。

- 仓库:https://github.com/DongYaoZe/visual-chem(本地 `d:\Documents\董耀择\dyz电子资料\5.化学\5.可视化`,git 根即此目录,web 应用在 `web/` 子目录)
- 线上:https://dongyaoze.github.io/visual-chem/
- 站训:**"the map is computed, not drawn"——所有图都是浏览器里逐点算出来的,不是画的**。这是全项目最高设计原则,任何新图面都必须由 `src/lib/chem/` 的计算内核驱动。

## 五、关键工程约定(踩过坑的)

- **验证命令**(8GB 机器必须限内存):
  ```bash
  cd web
  NODE_OPTIONS="--max-old-space-size=768 --max-semi-space-size=8" npx vitest run
  NODE_OPTIONS="--max-old-space-size=768 --max-semi-space-size=8" npx svelte-check --threshold error
  npm run lint            # prettier --check + eslint,CI 的红灯多半死在这
  NODE_OPTIONS="..." npm run build     # 产物到 build/,404.html 回填 base
  NODE_OPTIONS="..." npm run test:e2e  # 自动起 serve:pages(4173,Pages 语义)
  ```
- **CI 等价于** `npm run validate`(lint+check+vitest)+ build + e2e。**push 前必跑 `npx prettier --write .`**——已有两次 CI 红灯都是格式/ lint(最近一次:`no-loss-of-precision`,黄金角字面量多写了一位;JS 双精度放不下的字面量会被 eslint 拦)。
- **Svelte 5 runes**;组件内不用 `{@html}`(KaTeX 走 `Math.svelte`,其 display 模式已带 tabindex=0 + role="math",不要回退);each 必须带 key;eslint 禁未用变量(`Array.from({length:n},(_item,index)=>index)`,不要 `as _, i`)。
- **粒子位置全部确定性 index-hash,运行时禁 Math.random**;动画全部 `@media (prefers-reduced-motion: reduce)` 关停。
- **axe 门禁**(serious/critical=0):小字号彩色文字对比度≥4.5(#207f8c 在米色底上是 4.27,会挂——深色变体用 #175059);可滚动区域必须可聚焦。
- **场景对齐 spec 是防腐层**:任何一方(zh/en/场景指令)增删幕,spec 必须先红。写内容时 scenes 数组的 id 顺序三方一致,kickers 是 `Record<Id, string>`('00'、'01'…)。
- **中国网络**:git push 失败时回退 `git -c http.proxy=socks5h://127.0.0.1:10808 push origin main`;GitHub API 用 curl 同样代理回退;WebFetch 常被墙,用 WebSearch。
- **CI 轮询**:push 后 `sleep 280` 再查 `api.github.com/repos/DongYaoZe/visual-chem/actions/runs?per_page=2`,双 success 后 curl 线上 URL 验 200。
- **提交风格**:每季分 3 个逻辑提交(内核 / 内容 / 组装),叙事式英文标题+正文(看 `git log` 最近 7 条),尾部 Co-Authored-By。
- **后台代理注意**:面板类组件可契约式委派(给足 props 契约+exemplar 清单,一次通过率高);但组装类大组件(Story/TriView)委派曾两次因 API 限额/会话退出中断,**主会话直接照模板写更稳**。代理被用户停止后不可 SendMessage 复活,直接自己补。
