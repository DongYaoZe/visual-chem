# VisualChem 真人学习验证方案

> 版本：2026-08-16  
> 对象：第一篇《永远到不了的 100%》、氢原子线光谱、CO₂ 红外振动三篇旗舰  
> 状态：**测试协议已准备；尚无真人结果。** 自动化、Axe、截图和连续录屏不能代替本协议。

## 1. 这轮验证要回答什么

这轮不再问“页面能不能跑”，而问四件更难的事：

1. 学生是否能在没有旁白救场的情况下理解三重表征之间的因果关系；
2. 交互是否帮助学生形成可迁移的化学模型，而不是只会读当前页面；
3. 文献数据、教学模型和解释性动画的证据边界是否真的被学生读懂；
4. 键盘与真实读屏器用户能否完成与视觉用户等价的核心学习任务。

成功标准不是“大家都说好看”。真正的证据是：学生能预测、操作、解释、迁移，并且错误心智模型在交互之后减少。

## 2. 受试者与分配

### 2.1 学生样本

首轮招募 **8–12 名目标学生**，用编号 `P01`–`P12` 记录，不在研究笔记中保存姓名。

建议覆盖两类背景：

- 约一半：正在学习或刚学完大学普通化学 / 物理化学相关章节；
- 约一半：学过先修课程，但没有专门准备本页主题。

不要只找项目熟人或高年级化学竞赛型学生。首轮目的不是做统计显著性，而是尽快暴露重复出现的认知断点。

### 2.2 故事分配

为控制疲劳，每名学生完成：

- 第一篇《永远到不了的 100%》：所有人必测；
- 氢谱与 CO₂：二选一，交替分配，使两篇各获得至少 4–6 名学生。

单人总时长控制在 **45–60 分钟**。如果一名学生同时完成三篇，后半段数据很容易被疲劳污染。

## 3. 主持人规则

### 3.1 开场词

主持人只说：

> 这不是在考你，也不是在测试你会不会化学；我们是在测试页面。请把你现在注意到什么、以为下一步会发生什么、哪里不确定，都直接说出来。页面让你困惑时，不需要替它找理由。

### 3.2 禁止的提示

主持人不能说：

- “你看右边那张图”；
- “这里其实是共沸点”；
- “再点三次就会出现按钮”；
- “偶极矩要变化才吸收”；
- “这个公式应该这样理解”。

只允许使用三级救援：

1. **R1：**“你现在会尝试什么？”
2. **R2：**“页面上有没有什么东西看起来可以操作？”
3. **R3：**明确指出控件位置，但不解释答案。

任何使用 R2 / R3 的任务都必须记录；R3 视为该任务“未独立完成”。

---

## 4. 每名学生的固定流程

1. 背景问答：3 分钟；
2. 对第一篇做 3 道预测题：3–5 分钟；
3. 第一篇自由阅读 + 指定任务 + 出声思维：20–25 分钟；
4. 第一篇 3 道迁移题：5 分钟；
5. 氢谱或 CO₂ 的 3 道预测题：3 分钟；
6. 第二篇自由阅读 + 指定任务：10–15 分钟；
7. 第二篇 3 道迁移题：5 分钟；
8. 结束访谈：3–5 分钟。

主持人记录时间点，但不要频繁打断。

## 5. 第一篇《永远到不了的 100%》

### 5.1 前测 / 预测题

**E-P1** 一锅乙醇—水混合物反复“达到气液平衡 → 取蒸气 → 完全冷凝 → 再加热”。你预计乙醇浓度会：

- A. 最终一定到 100%
- B. 越来越高，但可能停在某个组成
- C. 一直保持不变
- D. 不确定，请说明原因

**E-P2** 某一步液相乙醇摩尔分数为 `x=0.30`，与它平衡的气相为 `y=0.50`。若把这股蒸气完全冷凝，新液体的乙醇摩尔分数最接近多少？请说明。

**E-P3** 如果一条平衡映射在某个组成满足 `y(x)=x`，你觉得继续重复上述步骤会发生什么？

### 5.2 页面任务

主持人只读任务，不解释做法。

**E-T1 预测钩子** 先做页面最开始的预测，然后亲手重复平衡级数。说出你什么时候开始改变对“能否到 100%”的判断。

**E-T2 x→y 映射** 在“一条结线”一幕解释：装置中的液体 `x`、平衡蒸气 `y`、相图上的两个点分别是什么关系。要求学生用自己的话把一次“液 → 气 → 冷凝液”讲完整。

**E-T3 文献证据** 在“把实验表重新变回一张地图”中自己选择文献样品。问：“你凭什么认为自己已经覆盖了整条相界，而不是只看了附近几个点？”

**E-T4 固定点** 用滑杆找到页面的 `x=y` 锁定态。问：“这个视觉锁定在数学上和蒸馏操作上分别意味着什么？”

**E-T5 越过共沸限制** 到“改变操作”后问：“为什么分子筛可以继续改变组成，而继续加理想平衡级不行？”

### 5.3 迁移题

**E-X1** 某未知二元体系的平衡映射满足：低组成区 `y>x`，高组成区 `y<x`，两者在 `x=0.72` 相交。若从 `x=0.30` 开始重复理想平衡级，长期最可能趋向哪里？为什么？

**E-X2** 同一实验数据可被模型 A 和模型 B 近似。A 在共沸组成附近非常准，但全区间偏差较大；B 全区间残差更小。问：“如果要解释实验数据，为什么不能只因为 A 的共沸点对了就说 A 是‘真实曲线’？”

**E-X3** 一个分离方法不是通过改变气液平衡映射，而是选择性移走其中一个组分。它是否必须受原来的 `x=y` 固定点限制？请用质量守恒和操作机制解释。

## 6. 氢原子线光谱

### 6.1 前测 / 预测题

**H-P1** 为什么氢放电管不是连续彩虹，而只出现少数谱线？

**H-P2** 对同一原子，若跃迁能量差更大，发出光的波长应更长还是更短？

**H-P3** 多条跃迁若都落到 `n=2`，你预计它们之间会有什么共同特征？

### 6.2 页面任务

**H-T1** 操作 Balmer 线的上能级，要求学生同时指出放电管、能级差与谱线位置三处怎样一起变化。

**H-T2** 把共同下能级切换为 `n=1 / 2 / 3`，解释为什么整组谱线会移动到紫外、可见或红外区域。

**H-T3** 在 sandbox 中自己找一条可见、一条紫外、一条红外跃迁，并解释“越高的起点”为什么不等于“波长一定越长”。

### 6.3 迁移题

**H-X1** 两次跃迁分别释放 1.9 eV 与 3.0 eV，哪一个光子波长更短？说明依据。

**H-X2** 一个新原子也只有离散能级。如果很多跃迁共享同一个下能级，你预计谱线会完全等间隔吗？为什么不能仅凭“能级是离散的”推出等间隔？

**H-X3** 仪器记录到一条人眼看不见的谱线，是否意味着“没有光子发出”？请区分光子存在、波段和人眼可见性。

## 7. CO₂ 红外振动

### 7.1 前测 / 预测题

**C-P1** 分子发生振动，就一定会吸收红外光吗？为什么？

**C-P2** 线性 CO₂ 两侧 C=O 键同时等量伸长再等量缩短时，你预计总偶极矩会不会随时间变化？

**C-P3** 波数从 `667 cm⁻¹` 增大到 `2349 cm⁻¹`，对应波长会变长还是变短？

### 7.2 页面任务

**C-T1** 比较对称伸缩和反对称伸缩。要求学生沿页面的因果总线完整说出：`正常模 → Δμ → 红外响应 → 谱峰`。

**C-T2** 在 `Δμ=0` 的静默模式上问：“原子明明动了，为什么因果链在这里断掉？”

**C-T3** 在 sandbox 中切换三种正常模并改变示意振幅。问：“振幅滑杆改变了什么？它有没有在宣称真实谱峰强度？”

### 7.3 迁移题

**C-X1** N₂ 是同核双原子分子。只考虑最基本的伸缩振动时，你预计它的电偶极红外基本频率是否活跃？说明理由。

**C-X2** HCl 的键伸缩会改变电荷分布和偶极矩。与 N₂ 相比，你预计它的基本伸缩是否更可能红外活跃？为什么？

**C-X3** 两个红外峰分别位于 `1000 cm⁻¹` 和 `2000 cm⁻¹`。哪一个对应更短波长、更高光子能量？

## 8. 主持人观察表

每个任务记录一行：

| 字段                 | 记录方式                           |
| -------------------- | ---------------------------------- |
| Participant          | `P01`–`P12`                        |
| Story / Task         | 如 `E-T2`                          |
| Start / End          | 时间戳                             |
| Independent success  | Yes / No                           |
| Rescue               | `R0 / R1 / R2 / R3`                |
| First wrong model    | 学生第一次明确说出的错误解释       |
| Representation break | 宏观 / 微观 / 符号 / 跨表征        |
| Evidence confusion   | 实验 / 模型 / 示意是否混淆         |
| Interaction failure  | 找不到、误点、反馈不明显、状态不懂 |
| Quote                | 最能说明问题的一句原话             |
| Severity             | S0–S3                              |

严重度定义：

- **S0**：偏好或审美，不影响理解；
- **S1**：短暂停顿，可自行恢复；
- **S2**：需要 R2/R3，或形成错误解释但后续能纠正；
- **S3**：核心概念被稳定理解错、无法完成任务、或界面让学生得到相反结论。

同一问题若在 **≥3 名学生**身上重复出现，即使都是 S1，也进入下一轮产品修复清单。

## 9. 学习结果怎么记，不怎么“做统计”

首轮样本很小，不把 8–12 人包装成证明教学效果的实验。

记录：

- 每道预测 / 迁移题：`0=错误或无解释`、`1=方向对但理由不完整`、`2=正确且理由成立`；
- 每人核心任务独立完成率；
- R2 / R3 次数；
- 首次有效交互时间；
- 重复出现的错误心智模型；
- 迁移题是否仍需要页面原句才能作答。

可以报告中位数、范围和逐题正确率；**不要在首轮小样本上做“显著提高 x%”的宣传。**

### 9.1 首轮 go / no-go 门槛

旗舰故事进入公开 Beta 前，至少满足：

- 无重复出现的 S3；
- 核心任务独立完成率 ≥ 80%；
- 每个关键概念至少 80% 学生能在迁移题中给出方向正确的解释（得分 ≥1）；
- “实验数据 vs 教学模型 vs 解释动画”的边界没有被 ≥20% 学生稳定混淆；
- 没有一个核心控件需要 ≥20% 学生使用 R3 才找到。

若不满足，先修界面/叙事，再招下一小轮；不要通过给主持人更多提示来“提高成功率”。

## 10. 结束访谈只问五个问题

1. 哪一刻你第一次觉得“我明白它在干什么了”？
2. 哪一刻你最不确定页面想表达什么？
3. 有哪一张图你看了，但其实不知道它为什么要在那里？
4. 如果明天考试出现一个不同体系，你觉得今天哪条关系还能用？
5. 如果只能删掉一个交互或一段文字，你会删什么？

最后一个问题很重要：它能迫使产品继续“少做内容、深做体验”。

## 11. 教师科学审校

至少请 **1 名相关课程教师**逐篇审校；更理想是物化方向审第一篇、结构/光谱方向审氢谱与 CO₂。

教师不需要评价 CSS，而逐项签：

- 数值、单位、符号和量纲是否正确；
- 术语是否与常见大学教材兼容；
- 图中因果箭头是否可能暗示错误机理；
- “实验事实 / 校准模型 / 理想模型 / 示意动画”标签是否足够明确；
- 省略项是否会改变当前教学结论；
- 中文是否有会误导学生的过度简化；
- 英文镜像是否保持相同科学边界；
- 迁移题是否真的考迁移，而不是复述页面。

每个问题标 `Accept / Revise / Block`。任何 `Block` 在公开 Beta 前必须关闭。

## 12. 真实读屏器验收

自动 Axe 已经是门禁，但真人读屏走查必须另外做。

### 12.1 Windows：NVDA + Chrome

至少完成：

- 从页面标题、header 到第一主标题的阅读顺序；
- 只用键盘完成第一篇预测与三次加级；
- 打开/关闭“查看当前图”对话框，确认焦点进入、Esc 关闭、焦点返回；
- 所有 slider 能读出名称、当前值和变化后的值；
- 数学公式至少有可理解的文本/数学语义，不只读成无意义字符；

- 全局暂停动画可被发现和操作；

### 12.2 Apple：VoiceOver + Safari

重复同一组核心任务，重点检查：

- rotor 中 heading / control 导航是否合理；

如果暂时没有 Apple 设备，状态必须写成“未验收”，不能由 Chrome 模拟替代。

## 14. 每轮测试结束后的产品流程

测试当天只记录，不边测边改。

全部 8–12 人完成后：

1. 合并重复问题；
2. 按 `S3 → S2 → 重复 S1` 排序；
3. 每个问题写成“观察 → 错误心智模型 → 可能原因 → 最小修复 → 回归方式”；
4. 只修最影响理解的 3–5 项；
5. 自动化回归；
6. 再做 4–6 人小轮验证。

只有当第二小轮没有重复 S3、核心任务和迁移门槛均达标，才把旗舰故事从“工程完成”升级为“学习体验已验证”。
